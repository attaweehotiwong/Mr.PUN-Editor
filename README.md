# MiniCut Studio

เว็บตัดต่อวิดีโอพร้อมซับไตเติ้ลภาษาไทย + อังกฤษ สไตล์ Minimal สำหรับ VS Code

## ความสามารถ
- นำเข้าวิดีโอผ่าน file picker (มือถือสามารถเลือกจากคลังรูปภาพหรือแอปไฟล์ได้ตาม browser/OS)
- AI ถอดเสียงจากวิดีโอและแปลเป็นภาษาอังกฤษ พร้อมเวลาแต่ละช่วงจาก Whisper
- แก้ไขข้อความและเวลา เพิ่ม/ลบซับไตเติ้ล
- ปรับฟอนต์ สี ขนาด ตำแหน่ง เส้นขอบ และพื้นหลัง
- ส่งออก MP4 โดยฝังซับไตเติ้ลลงในวิดีโอด้วย FFmpeg
- บนอุปกรณ์ที่รองรับ Web Share จะเปิดเมนูแชร์ไฟล์ เพื่อเลือกบันทึกลง Photos/Files ได้; หากไม่รองรับจะดาวน์โหลดไฟล์

## สิ่งที่ต้องติดตั้ง
1. Node.js รุ่น 20 หรือใหม่กว่า
2. VS Code
3. OpenAI API key สำหรับระบบถอดเสียงและแปลภาษา (มีค่าใช้จ่ายตามการใช้งาน API)

## วิธีเปิดโปรเจกต์
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `minicut-studio` ด้วย VS Code
3. เปิด Terminal ใน VS Code
4. รัน `npm install`
5. คัดลอก `.env.example` แล้วเปลี่ยนชื่อเป็น `.env`
6. เปิด `.env` และใส่ API key ใน `OPENAI_API_KEY=...`
7. รัน `npm run dev`
8. เปิด `http://localhost:5173`

## หมายเหตุสำคัญ
- ห้ามนำ `.env` หรือ API key ขึ้น GitHub หรือใส่ไว้ในโค้ดหน้าเว็บ
- ระบบถอดเสียงต้องเชื่อมอินเทอร์เน็ตและมี API key ที่ใช้งานได้
- การประมวลผลวิดีโอและส่งออกใช้ FFmpeg บนเครื่องที่รัน Backend; วิดีโอขนาดใหญ่ใช้เวลาและพื้นที่มาก
- ขณะพัฒนาในคอมพิวเตอร์ `localhost` จะไม่เปิดจากมือถือโดยอัตโนมัติ หากต้องทดสอบบนมือถือให้เปิดผ่าน HTTPS deployment หรือเครือข่ายเดียวกันพร้อมตั้งค่า host/firewall
- การเลือกคลิปจาก Photos ขึ้นกับระบบปฏิบัติการและเบราว์เซอร์ โดย `<input type="file" accept="video/*">` จะเรียกตัวเลือกสื่อ/ไฟล์มาตรฐาน
- ไฟล์วิดีโอที่ส่งออกจะเป็น MP4; การบันทึกเข้า Photos โดยตรงขึ้นกับระบบปฏิบัติการ จึงใช้เมนูแชร์หรือดาวน์โหลดเป็นทางเลือก
- ฟอนต์ที่เลือกจะถูกส่งเป็นชื่อฟอนต์ให้ FFmpeg/ระบบฟอนต์บนเซิร์ฟเวอร์ หากเซิร์ฟเวอร์ไม่มีฟอนต์นั้น อาจแสดงเป็นฟอนต์ทดแทน ควรติดตั้ง Noto Sans Thai บนเครื่องเซิร์ฟเวอร์เพื่อให้ภาษาไทยแสดงผลถูกต้อง
- การใช้งานจริงบนอินเทอร์เน็ตควรเพิ่มระบบยืนยันตัวตน, จำกัดขนาด/จำนวนงาน, rate limit และตั้งค่า storage ชั่วคราวให้เหมาะสม
